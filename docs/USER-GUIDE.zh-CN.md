# Luma Stereo 1.1.2 使用说明

开发人：redokeillo。新旧版本的文件、设置独立；不会覆盖旧版。试用时请先停止旧版音频转发，避免两版同时输出同一声音。

## 连接自己的音箱

1. 在 Windows 蓝牙设置中连接两只音箱，确认都出现在 Windows 声音输出设备中。
2. 推荐从 [VB-Audio 官网](https://vb-audio.com/Cable/) 安装 VB-CABLE，并按官方提示重启。程序不自动安装驱动。
3. 将 Windows 或播放器输出设为 CABLE Input。
4. 完整解压便携包，运行 LumaStereo.exe。仪表盘中选择声音来源，以及左右两只音箱。三个端点必须不同。
5. 返回主页，点击浅色电源图标开启播放。名称不限于 Q26，实际兼容性取决于驱动及蓝牙适配器。

## 主界面与动画

- 总音量支持点击、拖动细竖线把手或键盘方向键调节。默认修改 Windows 总音量，也会同步系统音量键的变化。
- 左右音量图标分别打开相对音量滑块；数字只在编辑时显示。再次点击或闲置约 4 秒会平滑收起，卡片随之缩小。鼠标或键盘焦点在滑块上时保持展开。
- 相对音量与总音量相乘，保持左右比例。例如总音量 50%、左相对 80%、右相对 60%，有效软件增益为 40% / 30%。
- 关闭“系统音量作为总音量”后，总音量调整应用内部增益，不修改 Windows 音量。
- 鼠标离开整个窗口 5 秒，左右操作卡片滑向两侧隐藏，只留两条极简软件缓冲竖条。总音量收起为底部细条，窗口控制仍显示。移回鼠标或用键盘操作即可恢复；打开仪表盘时不进入此模式。
- 顶部最小化、最大化/还原、关闭图标融入磨砂背景。顶部空白区域可以拖动窗口，双击可最大化/还原。最大化时取消外圆角，普通窗口采用 32 DIP 大圆角。

## 桌面透明与性能

仪表盘 → 桌面与启动 → “桌面磨砂透明”。开启时显示窗口后方模糊的桌面内容，可能是壁纸或其他窗口；最大化时使用系统静态壁纸磨砂层，不显示动态壁纸动画或后方应用窗口。

Windows 11 优先使用系统亚克力；兼容模式尝试旧版亚克力。不支持、远程桌面或系统关闭透明效果时，实际呈现可能不同。关闭此选项会改成不透明深色背景，减少系统合成负担。

动态频谱是另一独立开关。关闭后停止频谱采样、FFT 和色块动画；透明效果与频谱可以分别关闭。

## 托盘

默认启用“最小化到托盘”。点击最小化后，窗口从任务栏隐藏，音频继续播放，系统音量继续同步。

在托盘期间，不运行界面动画定时器，不采集输出用于频谱，不计算 FFT。只保留音频线程和约 200 ms 一次的控制状态检查；不是退出程序，也不承诺 CPU 占用为零。

单击托盘图标或再次运行 LumaStereo.exe 可恢复原窗口。托盘右键提供显示、播放/暂停、退出。关闭窗口的 X 是真正退出，会停止转发，不是收进托盘。

关闭“最小化到托盘”后，最小化留在任务栏，视觉更新仍暂停。

## 开机自启与自动播放

仪表盘 → 桌面与启动 → “开机自启 · 打开即播放”，默认关闭。

开启后注册当前 Windows 账号登录时启动的项目；以后每次手动打开或登录启动，都会按已保存设备自动尝试播放。若设备尚未连接，最多等待约 60 秒，每 3 秒重试一次。设备不就绪时保持未播放，可连接后手动点击电源图标。

通过登录自启打开且启用托盘时，会进入托盘。再次打开或点击托盘图标恢复。关闭自启选项会删除本程序自己的登录启动项，同时关闭打开即播放。

请先把程序放在长期保留的目录，再开启自启。移动程序后应在新位置重新关闭、开启一次自启。不会要求管理员权限。注册位置为当前用户 Run 项，键值名 redokeillo.LumaStereo.1.1.2，不修改其他应用的启动项。

## 延迟与校准

仍只有“低延迟模式”和“稳定模式”，软件缓冲目标分别为 25 ms / 150 ms。驱动实际采集块较大时会增加必要余量；显示的缓冲不是端到端蓝牙延迟。

停止播放后切换模式。用“左右交替”确认摆放，再用“同步短音”给先响的一只增加延迟，点击应用；完成后关闭校准音。

每侧支持 0–2000 ms 追加延迟。“去掉共同延迟”保留左右差值，减少无意义等待，例如 120/127 变成 0/7 ms。

蓝牙编码与音箱自身延迟不能用负延迟消除；视频仍声晚于画时，可在支持的播放器里调整音频提前或视频延后。

## 配置与迁移

1.1.2 配置：`%LOCALAPPDATA%/redokeillo/LumaStereo-v1.1.2/settings.xml`。
首次启动可读取旧版本配置，依次尝试 1.1.1、1.1、1.0，之后只保存到新版本目录。个人设备标识仅保存在本机，不要把此文件上传 GitHub。

本地处理音频，不录音、不上传、不包含遥测。源码与发行包中不含使用者的音频设备标识。

无声音时检查声音来源、系统静音、音箱硬件音量；设备掉线后重新连接并刷新设备。软件欠载持续增长时，先关闭频谱或透明，再使用稳定模式。

V1.1.2：总音量横条支持点击、拖动和键盘方向键；细竖线把手。默认直接调 Windows 总音量，关闭系统跟随后调整应用音量。最大化壁纸为缓存的静态磨砂图片，透明开关可关闭。
